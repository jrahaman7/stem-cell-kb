# Cell Therapy Knowledge Base

A knowledge base portal for researchers working on customized stem cell and cell therapies for US patients.

Sections: regulatory navigator (361 vs 351 self-check), pathways to patients, FDA-approved products directory (55 products), clinic verification checklist, 2030 care-delivery roadmap (scenario), researcher resources, and advisory contact.

Built with Next.js; deployed on Vercel. Content reviewed November 15, 2026. Not affiliated with FDA; not medical or legal advice.

```
npm install
npm run dev
```
